1Scope

1.1This policy applies to the YT Shorts Away app for iPhone and its Safari web extension (together, “YT Shorts Away”).

1.2“The developer” means the developer of YT Shorts Away. “You” means a person using YT Shorts Away.

2How YT Shorts Away operates

2.1The app guides you through installing the extension and granting it permission.

2.2When the extension is enabled and has been granted access to YouTube in Safari, it examines page elements and links on YouTube in order to hide Shorts.

2.3When a Shorts link is opened, the extension applies the handling you have selected.

2.4These functions operate in the browser.

3Information the developer receives

3.1The developer receives no browsing activity, settings, or usage analytics from the app or the extension.

3.2If you email the privacy contact, the developer receives your message and email address. See section 8.

4Information stored in the browser

4.1Browser extension storage holds the values listed in Table 1 so that your settings are kept across uses.

Table 1. Values held in browser extension storage
Value What it records Why it is stored Kept until
On/off status Whether YT Shorts Away is on or off To keep the setting across uses It is changed or cleared
Shorts link handling preference The handling you selected for opened Shorts links To keep the setting across uses It is changed or cleared
Custom CSS selectors Selectors you have entered To keep the setting across uses They are changed or cleared. Saving an empty list clears them.

4.2Where browser-managed extension sync is available and enabled, the browser may sync these values.

5Retention

5.1Stored preferences remain until they are changed or cleared.

5.2Retention of any synced values is managed by the browser provider.

6Your controls

6.1The controls listed in Table 2 are available to you.

Table 2. Controls
Control How to use it
Pause YT Shorts Away Use the toolbar popup.
Revoke access to YouTube Revoke the extension’s YouTube site access in Safari settings.
Clear custom CSS selectors Save an empty selector list.
Manage stored and synced settings Use the browser’s controls for stored and synced settings.

7Third-party services

7.1YouTube. Visits to YouTube are handled by Google under the Google Privacy Policy.

7.2Policy hosting. GitHub Pages hosts this policy. GitHub logs visitor IP addresses for security. See the GitHub General Privacy Statement.

8Contact and requests

8.1Questions and deletion requests may be sent to privacy@alleycatlabs.com.

8.2If you send an email, your message and email address are used to respond to you.

9Changes to this policy

9.1If this policy is changed, the updated version will be posted on this page.
